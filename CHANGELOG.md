# Changelog

## 0.1.0-alpha

- Rebuilt VoiceInk as a native macOS menu bar app using SwiftPM and AppKit.
- Added global `Ctrl+Shift+S` recording toggle.
- Added Gemini transcription, clipboard copy, and Accessibility-based auto-paste.
- Added a settings window with Keychain-backed Gemini API key storage.
- Added local installer, app bundle build script, smoke tests, and Swift formatting checks.
